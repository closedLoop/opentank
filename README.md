# opentank
(WORK IN PROGRESS) A smart home sensor hub with ESP32-C6, rich analog capabilities, and full self-powering.
## Important note!!!
The D-/D+ lines at the Type-C connector and SDA/SCL lines for U17 are still swapped!!! If you want to modify this and make changes for your own project, keep this in mind! Otherwise feel free to have a peak around in the PCB layout.
